# Shared Class Project Instructions

Multiple students develop this application in separate Codex chats connected to the same GitHub repository. Follow these rules for every task:

1. Before making changes, retrieve the latest version of the repository. Check for local changes first, then fetch and safely incorporate the latest changes from the shared branch.
2. Preserve all existing application functionality.
3. Do not overwrite or discard another student's work, including local changes and changes already committed to GitHub.
4. After completing a task, test the changes and commit them with a descriptive commit message. If tests are unavailable or cannot run, explain that limitation.
5. Push completed changes to the shared GitHub repository.
6. Immediately before pushing, fetch and check whether other students have pushed new changes. If so, incorporate those changes safely and rerun relevant tests before pushing. If the push is rejected because the remote changed again, repeat this process.
7. If conflicting changes cannot be safely combined, stop and explain the conflict rather than overwriting anyone's work.
8. Never force-push to the shared repository.
